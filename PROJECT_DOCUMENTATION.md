# Pit Lane - Diecast Racing Tournament Manager\n\n## Project Overview\n\n**Pit Lane** is an offline-first web application for managing diecast car racing tournaments. Built with modern web technologies, it allows users to catalog their diecast car collection, organize them into teams, and run competitive tournaments with various bracket formats. All data is stored locally in the browser, with no cloud storage or account requirements.\n\n### Key Features\n\n- **Car Garage**: Add and manage diecast cars with photos, specifications, and driver names\n- **Team Management**: Organize cars into teams with custom colors and branding\n- **Tournament Formats**: \n  - Single Elimination (losers are eliminated)\n  - Double Elimination (winners and losers brackets)\n  - Round-Robin (everyone races everyone)\n  - Time-Trial (individual timed races)\n  - Championship (qualifying round + finals)\n- **Automatic Bracket Generation**: Creates properly seeded brackets with bye handling\n- **Winner Propagation**: Automatically advances winners through the bracket\n- **Tournament Statistics**: Track wins, losses, and championships per car/team\n- **Data Backup**: Export and import tournament data as ZIP files\n- **Theme Support**: Light and dark mode with system preference detection\n- **Offline-First**: All data stored in browser's localStorage, no internet required\n\n---\n\n## Architecture Overview\n\n### Technology Stack\n\n- **Frontend Framework**: React 18+ with TanStack Start (full-stack React framework)\n- **Routing**: TanStack Router (file-based routing)\n- **Data Fetching**: React Query (TanStack Query)\n- **Styling**: Tailwind CSS 4 with Radix UI components\n- **State Management**: React hooks with localStorage persistence\n- **Build Tool**: Vite\n- **Package Management**: npm\n- **Server**: Cloudflare Workers (via wrangler)\n\n### Project Structure\n\n```\nsrc/\n├── components/              # React components\n│   ├── ui/                 # Radix UI wrapper components\n│   ├── Banner.tsx          # Dismissible notification banner\n│   ├── CarCard.tsx         # Car display card component\n│   ├── CarForm.tsx         # Car creation/editing form\n│   ├── SiteHeader.tsx      # Main navigation header\n│   ├── ThemeProvider.tsx   # Theme context provider\n│   ├── ThemeToggle.tsx     # Light/dark mode toggle\n│   └── ...        // Team sponsor\n  notes?: string;                // Additional notes\n  createdAt: number;             // Creation timestamp\n  wins?: number;                 // Team wins\n  losses?: number;               // Team losses\n  championshipWins?: number;     // Championship wins\n}\n```\n\n#### Tournament\nRepresents a racing tournament with matches.\n```typescript\ninterface Tournament {\n  id: string;                    // Unique identifier\n  name: string;                  // Tournament name\n  format: BracketFormat;         // Tournament format\n  participationType: \"cars\" | // Unique identifier\n  round: number;                 // Round number\n  slot: number;                  // Position in round\n  bracket?: \"winners\" | \"losers\" | \"final\"; // Bracket type\n  carAId?: string | null;        // First car ID\n  carBId?: string | null;        // Second car ID\n  teamAId?: string | null;       // First team ID\n  teamBId?: string | null;       // Second team Team series games\n  seriesLength?: number;         // Number of games in series\n}\n```\n\n### Bracket Formats\n\n1. **Single Elimination**\n   - Losers are immediately eliminated\n   - Winners advance to next round\n   - Simplest format for quick tournaments\n\n2. **Double Elimination**\n   - Winners bracket: losers are eliminated after a second loss\n   - Losers bracket: for teams that lose in winners bracket\n   - Grand final: winners bracket champion vs losers bracket champion\n   - Fair format allowing comeback opportunities\n\n3. **Round-Robin**\n   - Every participant races every other participant once\n   - Rankings determined by wins/losses\n   - Best for smaller groups (8-12 participants)\n\n4. **Time-Trial**\n   - Participants race individually on a track\n   - Rankings by fastest time\n   - No head-to-head races\n\n5. **Championship**\n   - Qualifying round (time-trial or round-robin)\n   - Finals bracket (single or double elimination)\n   - Top finishers from qualifying advance to finals\n\n---\n\n## Key Implementation Details\n\n### Tournament Bracket Logic (`src/lib/bracket.ts`)\n\nCore functions for managing tournament brackets:\n\n####
